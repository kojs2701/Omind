# 만들 것

## 프로젝트 이름
- O:mind(AI 활용 오답 복습 시스템)

## 목적
- 오답노트를 쓰는 것은 번거러워 하거나, 작성 이후에도 체계적인 복습이 되지 않아, 학습 효과가 나아지는 문제점을 해결.

## 작동원리
- 사용자가 업로드한 사진과 설명을 가지고 AI에게 질문 후 답변을 받아 오답노트 생성 및 복습 계획 생성.
- 더욱 맞춤형 서비스 제공을 위해 로그인 기능을 추가.
- DB는 firebase로 함.

### AI에게 질문
1. 오답 분석 에이전트: 문제 풀이 결과를 바탕으로 오답 원인을 분석.(출력 형식을 제한하여 불필요한 추론 방지)
2. 해설 생성 에이전트: 학습자의 수준을 고려해 맞춤형 설명 제공
3. 문제 생성 에이전트: 학습자의 수준에 맞는 유형별 맞춤형 문제를 생성
4. 학습 추천 에이전트: 사용자 맞춤 학습 추천 에이전트
   - 토큰 낭비를 최소화하기 위해 출력 형식을 고정, 명확한 지시.
   - AI에게 단순한 답변을 받아 그것을 그래프와 표로 출력할 수 있게 함.
   - AI는 기본적으로 Gemini로 작동한다.

## 페이지 구성

### 메인 페이지
- 가장 기본적인 페이지 이며 여러가지 페이지가 모여있으며 원하는 페이지로 이동할 수 있다.

### 오답노트 페이지
- 지금까지 틀린 문제들을 모아둔 페이지이며 해설과 오답분석 에이전트가 남긴 것을 모아두고 있다.

### 문제 페이지
- 자기가 부족한 부분을 보완할만한 문제를 모아둔 페이지이다.

### 학습 추천 페이지
- 자신의 문제를 요약해두고 관련된 계획표(망각 곡선을 이용한 복습 계획 등)을 짜논 페이지이다.

### 문제 전송 페이지
- 틀린 문제를 전송하고 그 답변을 받아올 수 있는 페이지이며 기본적인 설명과 문제 생성 여부 등을 선택할 수 있게 하여 에이전트가 더욱 확실한 답변을 받아올 수 있게 하는 페이지이다.
- 이때 올린 문제와 받아온 설명은 오답노트, 학습 추천, 문제 페이지에 저장된다.

### 점수 기록 페이지
- 자신의 내신 점수를 기록할 수 있는 페이지이며 자신의 성적을 저장해주고 시각적인 자료로 표현해주는 페이지이다.

## 디자인
- 이 페이지는 기본적으로 모바일, 컴퓨터에서도 작동되는 반응형 페이지이다.

### 상단
1. 이 페이지의 이름
2. 현재 들어가 있는 페이지의 이름(예 : 오답노트)
3. 현재 로그인한 계정
4. 빠르게 이동할 수 있는 네비게이션 버튼들

### 메인 페이지
- 이동할 수 있는 페이지가 모아져 있다.
- 아래에는 기본적인 설명과 장점이 들어가 있다.

### 오답노트 페이지
- 지금까지 틀린 문제를 모아두고 있으며 그 문제를 클릭할 시 그때 있었던 해설과 오답분석이 남겨져 있다. 이것은 표와 그래프, 글로 남겨져 있다. 
- 왼쪽에는 보냈던 사진과 설명, 오른쪽에는 해설과 오답분석이 있다.

### 문제 페이지
- 유형을 선택하고 원하는 문제를 선택하여 풀 수 있게 한다.(이때 문제는 답을 전송하면 맞는지 확인하고 맞다면 그 문제를 풀었다는 표식을 남긴다.)

### 학습 추천 페이지
- AI에게 받아온 데이터를 기반으로 체계적인 복습 계획과 잘맞는 공부법을 시각적인 데이터로 보여진다.

### 문제 전송 페이지
1. 사진을 전송할 수 있는 칸이 맨위에 존재한다.
2. 간단한 설명을 적을 수 있는 칸이 그 아래에 있다.
3. 그 아래에는 문제 생성 여부, 계획 생성 여부 등을 선택할 수 있는 칸이 있다.

## 파일 구성
- index.html: 메인 웹 페이지
- style.css: 스타일시트
- script.js: 프론트엔드 JavaScript
- server.js: 백엔드 서버
- agents/: AI 에이전트 모음
- services/: 외부 서비스 통합 (Gemini API, Firebase)
- .env: 환경 변수 설정
- README.md: 초기 프로젝트 기획
- project.md: 프로젝트 구현 설명서
- FIREBASE_SETUP.md: Firebase 설정 가이드
